# Grafana dashboards for SatPulse

These are some example dashboards that use the metrics exposed by satpulse.

- `phc.json` - graphs of PTP hardware clock offsets
- `signals.json` - GPS signal bar graph
- `skyview.json` - GPS sky view (requires [nLine Plotly.js plugin](https://grafana.com/grafana/plugins/nline-plotlyjs-panel/))
