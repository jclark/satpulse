This directory is designed to be served with GitHub Pages.

You can preview locally by first installing Ruby (e.g. on macOS do `brew install ruby`).
Then in this directory, run `bundle` to install the necessary Ruby dependencies.
Then also in this directory, run

```
bundle exec jekyll serve
```

While this is running, visit [`http://localhost:4000`](http://127.0.0.1:4000/).
