THis page lists specialist vendors that sell only precision time hardware.
Vendors that sell GNSS related hardware are on [GNSS hardware vendors]({% link hardware/vendors.md %}) page.

* [FS](https://www.fs.com/) make some inexpensive switches with PTP support.
* [Time Appliances](https://www.tindie.com/stores/timeappliances/) make the TimeHAT, which is a hat for a Raspberry Pi 5, with an Intel i226 NIC.
* [TimeBeat](https://store.timebeat.app/) are in London, UK. They make a board for the CM4/5 in a unique "sandwich" form factor.
