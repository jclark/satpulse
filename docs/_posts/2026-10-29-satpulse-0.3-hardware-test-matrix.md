More details on the machines that are new or have changed since the [0.2 hardware test matrix]({% post_url 2026-05-03-satpulse-0.2-hardware-test-matrix %}):

abondance
: ASUS S500SD desktop (Intel B660 chipset) with an Intel i5-12400 and 64 GB RAM. It has two Intel I225-T1 PCIe cards: one is connected to an internal ArduSimple simpleRTK2B M.2, which has a u-blox ZED-F9P, and the other is connected to a Septentrio mosaic-G5 P3 USB dongle from gnss.store. This supports cross-timestamping with [PTM]({% link hardware/ptm.md %}).

banon
: BeagleY-AI with 4 GB RAM, booting from a microSD card. GPS is an Allystar TAU951M-P200 connected to UART1; its PPS goes into the PHC of the onboard Ethernet (the CPTS) through header pin 33.

burrata
: Raspberry Pi CM4 with 1 GB RAM and 8 GB eMMC, in a Waveshare case, running 32-bit Raspberry Pi OS. GPS is a Zhongke ATGM332D-F8N-76 connected to UART0.

caciocavallo
: Raspberry Pi CM4 Lite with 2 GB RAM and a 64 GB SD card, on a Waveshare PoE Base Board B. GPS is a BG7TBL CM55 GPSDO, which has a LEA-M8T, connected over RS232 to UART3.

chaource
: Raspberry Pi CM4 Lite with 8 GB RAM, on the official IO board with a 256 GB NVMe SSD in the PCIe slot. GPS is an Allystar TAU1201 on a Star River SR1723TAU1201 board, connected to UART0.

ricotta
: Raspberry Pi CM4 with 8 GB RAM and 32 GB eMMC, on the official IO board. GPS is a Zhongke AT362-6T-30 connected to UART0.

roquefort
: Raspberry Pi CM4 with 4 GB RAM and 8 GB eMMC, on a Waveshare PoE board. GPS is a Quectel LG290P on a Mozihao breakout board, connected by USB.

serpa
: Raspberry Pi CM5 with 8 GB RAM and NVMe SSD, on a Geekworm X1500 carrier board. GPS is a Unicore UM980 connected to UART0.

vacherin
: Raspberry Pi CM5 Lite with 8 GB RAM and 500 GB NVMe SSD, on the official IO board. GPS is a u-blox EVK-X20P connected by USB.

valdeon
: Raspberry Pi CM5 with 4 GB RAM and 32 GB eMMC, on a Waveshare Mini Base Board (A). GPS is a u-blox MAX-F10S on a Timebeat sandwich board.

valtellina
: Raspberry Pi CM5 Lite with 8 GB RAM and NVMe SSD, on the official IO board. GPS is a Techtotop T303-5D connected to UART0.

venaco
: Raspberry Pi CM5 with 8 GB RAM and NVMe SSD, on the official IO board. GPS is a Zhongke ATGM332D-5N connected to UART0.

Compared to 0.2, the GPS modules I am testing are considerably more diverse. Notable additions are:

- from Zhongke Microelectronics using CASIC:
  - ATGM332D-5N is a very inexpensive, common, single-band module (module cost is $2 in quantity)
  - ATGM332D-F8N-76 is a very inexpensive dual-band module (module cost is $3 in quantity)
  - AT362-6T-30 is a modern, single-band timing receiver
- from Allystar:
  - TAU1201 is an inexpensive, common dual-band module (not quite as cheap as ATGM332D-F8N-76)
  - TAU951M-P200 is an RTK-capable dual-band module
- from Septentrio, mosaic-G5 P3 is a very nice but very expensive ($400) module
- from Techtotop (one of the main vendors of timing receivers in China, but not known in the West), the T303-5D is their latest dual-band timing receiver

On the OS side, I have SatPulse working on 32-bit architectures and test this on 32-bit armhf Debian.
I have also added Ubuntu.

On the PTP hardware clock side, SatPulse now works on the BeagleY-AI.
(Documentation has not been updated for this yet, but it needs a [device-tree overlay](https://github.com/beagleboard/BeagleBoard-DeviceTrees/blob/v6.18.x/src/arm64/overlays/k3-am67a-beagley-ai-cpts-hw1tspush-gpio13.dtso).)
