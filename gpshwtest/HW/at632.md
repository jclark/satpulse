# AT632-6T-30 / AT362-AT6668-6T-30 (URANUS6 V6.3.0.0)

CASIC timing receiver, single band, UART at 115200. The hardware
string says AT362 although the product is sold as AT632-6T-30.
Characterized 2026-06-13; baseline
`AT362-AT6668-6T-30-URANUS6,V6.3.0.0.json`.

## Limitations relative to the model

- Signals: L1-band only - GPS L1, GAL E1, BDS B1I+B1C, GLO L1,
  QZSS L1, SBAS L1. Requests for L5-band signals drop out via the
  chip's clamp of the reception mask. The same refusal rules as the
  F8N apply (augmentation-only or empty sets are refused).
- Leap second output (`leap`): TIM2-LS is acknowledged but is an
  event message; nothing appears within an observation window, so
  leap information shows as undelivered. Unlike the F8N, pulse-time
  (`tp` via TIM2-TPX) and survey progress (`survey` via
  TIM2-TIMEPOS) ARE delivered, and raw output (RXM2-MEASX/SFRBX)
  flows.
- RTCM output: CFG-RTCM is NAKed - RTCM configuration does not exist
  in this firmware (the port protocol-mask RTCM bit does stick).
  rtcmBaseID does not exist in the protocol.
- Fixed position: ECEF in 1 cm steps, accuracy in 1 mm steps; LLH
  requests realized as ECEF (LLH never reads back).
- Time pulse width quantized to 1 us.
- Active port: not identifiable (one port-query response per UART,
  nothing marks the current one).
