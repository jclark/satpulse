# AT372-F8P-36 (URANUS6 V6.5.1.0)

CASIC RTK-enabled dual-band positioning receiver (the -F8P class of
the AT9880), UART at 115200 through a CH341 adapter on VirtualHere
hub port 1 of edam (`/dev/ttyHUB1`). Characterized 2026-10-28
(non-disruptive, then disruptive); baseline
`AT372-AT9880-F8P-36-URANUS6,V6.5.1.0.json`.

## Starting state

The factory-default NMEA set (GGA, GLL, GSA, GSV, RMC, VTG, ZDA),
binary output off, CFG-NAVBAND as found (`sigBandAuto` 1,
`sigidMaskFix` 0, `sigidMask` 0x28CD8D: GPS L1+L5, GAL E1+E5a, BDS
B1I+B1C+B2a, QZSS L1+L5, SBAS L1), timing constellation BDS, mobile.
A completely quiet start is not restorable: restoring the protocol
selection after the `--binary` probe leaves NAV2-PVH and NAV2-TIMEUTC
on.

## Limitations relative to the model

- Signals: hardware set is GPS L1+L5, GAL E1+E5a, BDS B1I+B1C+B2a,
  GLO L1, QZSS L1+L5, NAVIC L5, SBAS L1, the same as the F8N.
- Time-of-pulse and leap-second output (`tp`, `leap`): not delivered.
  TIM2-TPX, TIM2-LS, TIM2-TIMEPOS, TIM2-TIMEGPS/BDS/GLN/GAL/IRN,
  TIM2-LY and TIM2-TCXO are all acknowledged and none is ever emitted
  (20 s with all enabled; NAV2-TIMEUTC emitted as a control).
- Survey: the request reads back (CFG-TMODE2 mode 1 with the duration
  and accuracy) but a 60 s, 20 m survey had not completed after 5
  minutes, and no output shows survey progress or a fixed mode:
  NAV2-SOL stays `fixFlags` 7 (3D) in survey and in fixed-position
  mode, as on the AT632.
- RTCM output: generated, unlike every other CASIC unit tested. It
  needs the port protocol-mask RTCM-out bit (CFG-PRT bit 7), which the
  configurator never sets, so through satpulsetool it is never
  emitted. With the bit set: MSM7 or MSM4 (CFG-RTCM `rtcm_msm_ver`)
  for GPS, GAL, QZSS and BDS at 1 Hz, 1005, and ephemerides 1019,
  1042, 1044, 1046. CFG-RTCM has no GLONASS bits and no GLONASS
  message appears with GLONASS enabled. The 1005 position is a frozen
  value that is neither the configured fixed position nor the current
  solution. MSM7 converts to dual-band RINEX with `convobs`.
- Raw output (`obs`, `nav`): RXM2-MEASX carries dual-band measurements
  on every enabled constellation, but only while CFG-NAVBAND
  `sigidMaskFix` is 0; any satpulsetool signal request writes it
  nonzero, after which MEASX carries no measurements (issue #526).
  gpshwtest's presence check does not see this.
- Reload: unsupported (V6 firmware); the load command restarts the
  receiver without acknowledging, and RAM configuration survives.
- Save granularity: a single group - saving anything saves everything.
- Fixed position: ECEF in 1 cm steps, accuracy in 1 mm steps; LLH
  requests realized as ECEF (LLH never reads back).
- Time pulse width quantized to 1 us.
- rtcmBaseID does not exist in the protocol.
- Active port: not identifiable.

## Notes

- CFG-NAVBAND persists across a power cycle without a save.
- With everything enabled the receiver tracks 76 signals (channel
  numbers up to 82), giving GLONASS only 2 satellites and NavIC none.
- The boot banner names the parts: `HW=AT372`, `IC=AT9880-F8P-36`.
