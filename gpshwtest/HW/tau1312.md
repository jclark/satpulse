# TAU1312 limitations

How device-independent configuration is realized on the L1/L5 Allystar
TAU1312 (HD9311.32690e91c), relative to the full model in `SEMANTICS.md`.
Measured on firmware 3.018.80db2889 on 2026-09-12 at UART 115200. This was a
non-disruptive run; save granularity, cold reset and factory reset have not
yet been characterized on this unit.

## Signals

The silicon accepts and reports GPS L1/L5, Galileo E1/E5a and BeiDou
B1I/B2a. Although receiver identity reports the generic Allystar five-GNSS
set, GLONASS and QZSS requests are clamped away: an all-GNSS request reads
back only GPS, Galileo and BeiDou, and GPS+QZSS reads back GPS alone. A
GLONASS-only request reads back the empty set. gpshwtest records both the
realized signal set and these identity-versus-silicon observations.

## Properties and message output

- Antenna cable delay, timing GNSS, fixed-position accuracy and RTCM base ID
  do not exist in the high-level model for this backend. The active UART is
  not identifiable through `--show-port`.
- Fixed positions are ECEF-only in storage with a 0.01 m quantum; geodetic
  requests are converted, and height is not stored separately.
- Time-pulse width has a 1 us quantum. Time-of-pulse and leap-announcement
  information are not delivered.
- The receiver declares raw output and RTCM MSM4/MSM7 (including QZSS)
  configuration support. No missing modeled RTCM output was observed in this
  run for the realized GPS/Galileo/BeiDou signal set.

## Physical PPS and receiver defect

The factory-disabled CFG-PPS block selects GPIO 0. It accepts high-level
pulse writes but GPIO 0 produces no signal on the module's PPS output. The
Allystar configurator now selects the documented PPS GPIO 13 on every write;
with that fix, gpshwtest observed 1 Hz edges on the FT232R CTS input while an
always-on 0.1 s pulse was enabled and no edges while disabled.

Like the TAU1302, zero-duty handling is not reliable after repeated pulse
writes. This run observed an ACKed request for width zero whose later
readback remained 0.1 s. The clean physical disable test did stop CTS edges;
the accepted-but-not-applied incidence occurs in the later scalar stress
sweep and is recorded as a receiver defect. Reloading restores the disabled
NVM state.

## Starting state

The observed state is mobile mode; GPS/Galileo/BeiDou L1/L5 signals; PPS
disabled with an all-zero CFG-PPS block; and NMEA GGA, GSA, GSV, GST, RMC and
ZDA output. GST is outside gpshwtest's restorable NMEA vocabulary, so
`setup/tau1312.sh` establishes the standard GGA/GSA/GSV/RMC/ZDA set before a
repeatable characterization. The checked-in non-disruptive baseline is
`TAU1312-3.018.80db2889.json`.
