# AT372-AT6668-6P-34 (URANUS6 V6.2.3.0)

CASIC RTK-enabled navigation receiver (the -6P precision variant of
the AT6668, sibling of the -6T timing variant), single band, UART at
115200. Characterized 2026-07-21; baseline
`AT372-AT6668-6P-34-URANUS6,V6.2.3.0.json`.

## Limitations relative to the model

- Signals: L1-band only - GPS L1, GAL E1, BDS B1I+B1C, GLO L1,
  QZSS L1, SBAS L1. L5-band requests are clamped away by the silicon
  (NAVIC, L5-only, drops out entirely). Requests naming only
  augmentation/regional systems are refused, like the other V6 units.
- Time-of-pulse and leap-second output (`tp`, `leap`): not delivered.
  Like the F8N, and unlike the -6T timing variant, the pulse-time
  fallback TIM2-TPX is acknowledged but never emitted.
- RTCM output: nothing is ever emitted, in any positioning mode. The
  unit is RTK-enabled in the sense of accepting incoming corrections;
  it does not generate them, the same as every other CASIC unit
  tested.
- Reload: unsupported (V6 firmware); unsaved changes survive a
  `--reload`.
- Save granularity: a single group - saving anything saves everything.
- Fixed position: ECEF in 1 cm steps, accuracy in 1 mm steps; LLH
  requests realized as ECEF (LLH never reads back).
- Time pulse width quantized to 1 us.
- rtcmBaseID does not exist in the protocol.
- Active port: not identifiable (one port-query response per UART,
  nothing marks the current one).
