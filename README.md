SatPulse is a suite of software for precision timing and positioning using modern GNSS receivers on Linux and other general-purpose operating systems.
Please see the [website](https://satpulse.net) for more information.
The documentation on the web site is mostly focused on the current released version.

See [NEWS](docs/_includes/NEWS.md) and the [blog](https://satpulse.net/blog.html) for recent developments.
Check the [Releases](https://github.com/jclark/satpulse/releases) page for the latest prerelease.

The website is built from the [`docs`](docs/) directory.
